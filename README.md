# NumPy Matrix Solver

A matrix solver built using NumPy as a project to practice NumPy.

## Features

- Matrix creation
- Matrix classification
- Matrix addition and subtraction
- Scalar multiplication
- Matrix multiplication
- Transpose
- Determinant
- Minors and cofactors
- Adjoint
- Inverse
- Systems of linear equations

## NumPy concepts used

- NumPy arrays
- Array indexing
- `shape`
- `reshape()`
- Array operations
- `np.dot()`
- `np.linalg`
- `np.delete()`
- `np.all()`
- `np.allclose()`

## Project

The main project is implemented in `matrix_solver_project_using_numpy.ipynb`.

## Why I built it

I built this project while learning NumPy, using matrices as a practical way to experiment with NumPy arrays and operations.
